# Diario de Hierro

App web instalable (PWA) para apuntar los pesos del gimnasio. Funciona sin internet y guarda los datos en el móvil.

## Actualizar la app
1. Cambia los archivos que quieras.
2. En `sw.js`, sube el número de `VERSION` (por ejemplo, de `v1` a `v2`).
3. Sube los cambios a GitHub. Al abrir la app con internet, aparecerá el botón **Actualizar**. Tus datos no se tocan.
